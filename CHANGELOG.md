# Changelog

## 0.40
- Black level: greys up to the chosen value go pure black, and white stays white (before, every tone was only shifted, so white turned grey).

## 0.39
- Dark pages: a Strength slider blends the filter with the untouched screen (0 = off, 100% = full).
- Dark pages: a Colours card shows ten sample colours as they are and as they will be.

## 0.20
- Colours: search, a collapsible list (dark colours only by default), "Backgrounds → black", "Text → white", and any colour can be set to another (from / to hex).
- Colours hidden by R8 (names like `0_resource_name_obfuscated`) are now matched by value.
- Settings → Data: export and import all settings as one JSON file; optional auto-backup file that survives an uninstall.
- Fix: the app no longer depends on the Xposed service provider to start.
- Shorter explanations on the app page.

## 0.19
- Earlier work (see the git history).
